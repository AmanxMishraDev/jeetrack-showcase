# Roadmap

What's planned, being explored, or shipped for JEETrack. This is a
solo-maintained project, so items move based on real engineering time and
what students actually ask for — feel free to weigh in via
[Discussions](../../discussions) or by 👍 reacting on related issues.

## 🔭 Planned

- [ ] **Revision scheduler with spaced repetition** — surface topics to
  revisit based on syllabus progress and time since last touched
- [ ] **Peer leaderboard (opt-in)** — compare streaks/progress with friends,
  opt-in only, no public rankings by default
- [ ] **JEE Previous Year Question (PYQ) tagging** — tag mock-test questions
  against past-year JEE questions for pattern recognition

## 🧪 Exploring

- [ ] **Offline AI insights** — an on-device model for basic insights when
  offline, since JEETrack is a PWA meant to work without connectivity
- [ ] **Public API for syllabus data** — considering exposing a read-only
  API for the JEE syllabus structure itself (not user data) if there's
  demand from other student-tool builders

## ✅ Shipped

- [x] AI-powered coaching insights (Groq / LLaMA 3.3 70B)
- [x] Monthly PDF report cards via email
- [x] Push notifications for daily study reminders
- [x] Support/donation flow (Razorpay, server-verified)
- [x] Internal admin dashboard (PostHog-backed)
