## What this repo is

This is the **documentation and community hub** for JEETrack — a mock-test,
syllabus-progress, and AI-insights web app for students preparing for
India's JEE engineering entrance exam.

JEETrack is spread across three repos, each with a different job:

| Repo | Purpose | Visibility |
|---|---|---|
| `JEETrack` (production) | Full source — frontend, database, edge functions, payments | 🔒 Private |
| [`jeetrack-showcase`](https://github.com/AmanxMishraDev/jeetrack-showcase) | Architecture write-ups and generalized engineering patterns | 🌐 Public |
| `jeetrack-docs` (this repo) | Docs, FAQ, roadmap, issue tracking, contribution guidelines | 🌐 Public |

The production source is kept private because JEETrack is a live product
handling real user data and payments (Razorpay). This repo — and the
showcase repo — exist so the project can still be transparent, open to
feedback, and open to contribution, without exposing anything that would
put user data or payment integrity at risk.

If you're looking for **how it's built**, see `jeetrack-showcase`. If
you're looking for **how to use it, report a bug, request a feature, or
understand how your data is handled**, you're in the right place.

## Reporting issues & requesting features

Use the [Issues tab](../../issues) with the appropriate template:

- 🐛 Bug report
- ✨ Feature request

For general questions or ideas that aren't quite a bug or a concrete
feature request, use [Discussions](../../discussions) instead.

**Found a security issue?** Please don't open a public issue — see
[SECURITY.md](SECURITY.md) for how to report it privately.
